# Elite Original V25
Crown Sigil and Aegis swept feather wearable meshes are original generated geometry, exported from the same runtime source to standalone GLBs. Optional selections attach to the torso bone and preserve original identity. Wings use hinge movement, not full feather simulation; fitting across every physique and collisions remain unverified. Existing high-density human mesh is retained; portrait surface tuning is not a bespoke photorealistic sculpt. 
Timeline retains V24 clip names and persists bounded per-step speed and blend; both backward-compatible legacy names and new timeline are saved via the existing Rich ID RPC. Creator exchange stores one private or published free wardrobe recipe per owner with RLS and explicit grants; only allowlisted fashion selections, not face/body/photo, may be shared. The owner can unpublish by saving a private draft. Paid items remain protected by V24 policies, and no Stripe checkout or new price is enabled. New curved vehicle geometry shares resources; offscreen world frames skip rendering. Original wearables asset manifest includes sizes and hashes. No homepage, Omni core, full portal or routing edits. Production build validates geometry and config, not authenticated browser behavior or device performance.
