# Rich Bizness HD character assets V21
The shared renderer admits compatible saved looks through Ara 3D Gen 0.19.0, with its pinned data 1.2.0. Code MIT, MakeHuman base assets CC0. Source: https://github.com/olatunde85/3d-gen and https://github.com/olatunde85/3d-gen/blob/main/scripts/ASSETS_LICENSE.txt. The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217. Motion data must not be resold independently.
Production build exports a real high-detail clothed male and low-detail clothed female GLB. Each must pass actual geometry, skinning, morph, texture and animation checks before release. The build publishes assets and an admission report including SHA256. All compatible avatars are rebuilt locally in a worker from their existing Rich ID appearance; no user identifiers are passed to Ara, and character data is served from the production origin. High detail is selected using the existing detail control; automatic uses mobile low and desktop medium. Unsupported existing hair/outfit/morph/stance/accessory choices retain the previous renderer with an explicit compatibility label. This is not a claim of a bespoke sculpt, AAA art direction, a fully migrated wardrobe, or professionally verified motion quality. Full-body walk/run/jump clips come from upstream retargeted CMU capture; gestures include authored clips. Actual iPhone frame rate, wardrobe fit, expressive fidelity and visual approval remain unverified. No schema, payment, homepage or portal changes. No automatic changes to saved preferences.
