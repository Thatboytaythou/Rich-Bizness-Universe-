# V31.1 vehicle admission correction
V31 production exported ten character GLBs including medium male 47,342 triangles and medium female 40,074 (low female 24,522), each with 69 joints. The desktop Spectral GT RS source passed build byte/triangle admission (151,722 triangles, 4,688,844 bytes), but was excluded on phones. V31.1 derives a static exterior-only variant by pruning named suspension, engine and secondary components from the exact pinned CC0 GLB, retaining body, cabin, windshields, four tires and rims. It removes animations, compacts binary views, then actually parses and merges both source and phone variants through the same GLTFLoader and mergeStaticVehicle implementation as the live city. The 85k triangle/36 draw mobile admission caps remain intact. The manifest reports each variant; failures retain the existing simpler parked vehicle. This is a build-time CPU verification, not a real-device WebGL guarantee. No Rich ID, database, payment, route or Omni core changes. Existing enhanced mobile character startup policy retained.
