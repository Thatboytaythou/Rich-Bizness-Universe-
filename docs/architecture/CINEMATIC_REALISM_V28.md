# V28 cinematic realism
Uses a grounded, warm-sun/cool-sky street look and photographic surfaces rather than flat diffuse colors. Four CC0 Poly Haven texture assets are vendored as lossless base64 representations of their existing JPEG files (source re-encodes in roszhan2684/california-drive, see ASSET_LICENSES.md); build verifies exact Git blob hashes before publishing. Asphalt 02, Brick Wall 001 and Concrete Wall 008 are third-party CC0, not original Rich Bizness photographic captures. Normal map on desktop; phone uses diffuse only. Texture requests are local, abort-aware, disposed with the district. Studio uses narrower portrait lens and directional light, retains fantasy treatment. Both character routes keep a 640-pixel mobile buffer ceiling and no mobile PMREM generation. No homepage, Omni navigation, identity data, Supabase or payment modifications. Existing human mesh and animation sources remain; buildings and vehicles retain their existing geometry. This is not GTA VI asset parity or a replacement human sculpt; actual iPhone performance and appearance require visual verification.
