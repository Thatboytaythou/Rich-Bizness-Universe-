# Character detail V17
Source: CMU Graphics Lab, subject 02 trials 01 (walk), 03 (run/jog); BVH conversion by Bruce Hahne, 2010. The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217. Mirror https://github.com/una-dinosauria/cmu-mocap and READMEFIRST.txt document commercial project use and conversion permission. Do not sell the source motion data itself. Walk source blob 5c5661c84c581711d3daa69d87c25b6a92ec4342, run b1827c0d03ebf474e518413aca7af300a3e65625. Source rotations resampled to 33 phase samples, mean centered, seam corrected and bounded. Walk uses frames 77–207, run uses frames 43–123 as an approximate cycle. Blend is 48% of bounded captured upper-body angles plus 52% existing authored animation; V16 contact solve remains responsible for legs. Not a full retarget or certified motion capture performance.
HumanForge v0.5.0 asset manifest and CC0 MakeHuman/MPFB base retained. New adult skin variants, brow and hair proxies, eye textures, hats and morphology fields are existing verified catalog entries; no new bespoke human mesh. Skin microtexture is procedural bump detail in high detail mode. Hair and cloth use bounded shader deformation (not physical collision simulation); fitted garments intentionally move very little. Face hair and independent clothing layers not supported. No schema, payment, world or homepage changes.
